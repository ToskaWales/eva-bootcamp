# eva-bootcamp

## Zoll-Trainer (`index.html`)
Offline-fähige Lern-App für den schriftlichen Zolltest. Fortschritt (Plan-Häkchen, Statistik, falsch beantwortete Fragen, Aufsatz-Entwurf, letzter Tab) wird lokal im Browser (`localStorage`) auf dem Gerät gespeichert – nichts verlässt das Handy.

**Aufs Handy:** Ordner über HTTPS hosten (z. B. GitHub Pages), Seite im Handy-Browser öffnen → „Zum Startbildschirm hinzufügen“. Danach läuft sie auch offline. Hinweis: Fortschritt gilt pro Browser/Gerät; Browserdaten löschen setzt ihn zurück.
